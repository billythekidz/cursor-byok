## Why Build This Project

Companies like to lock Agent services into specific models, forcing users to use tools only with designated models, specific subscriptions, and predefined billing models.

I want to break this lock-in: model choice should be free. Developers should be able to connect their own model APIs to any IDE, Chat app, Agent, or development tool, or self-host the entire service stack to avoid platform lock-in.

The goal of this project is to return model choice back to the users.

## Future Plans

We will continue to expand support for more tools and use cases, including but not limited to:

- Supporting more IDE integrations
- Supporting more Chat applications
- Supporting more Agent tools and workflows
- Providing more comprehensive self-hosted deployment options
- Continuously optimizing compatibility across different model APIs
- Reducing integration costs to maximize usage of existing model quotas

Ultimately, we aim to enable your model APIs to connect freely to any tool you wish to use.
